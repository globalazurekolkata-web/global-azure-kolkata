About the Event

Where the Azure
Community Meets

Global Azure is a community-run event organized every year by passionate Azure enthusiasts around the world — simultaneously — celebrating the power of Microsoft Azure and cloud technology.

The Kolkata edition brings together developers, architects, data engineers, AI practitioners, and cloud professionals for a full day of learning, networking, and inspiration. All sessions are free to attend.
