Accepted Sessions

Talks & Sessions

Curated sessions covering the full breadth of the Azure ecosystem — from AI to infrastructure.

01

The Knowledge Fabric: Unifying IT, OT & AI for Industrial Transformation

Ambarish Ganguly

Industrial organizations generate massive amounts of data across engineering documents, EAM systems, sensors, SCADA, edge devices, and the web. Yet most of this knowledge remains fragmented. In this session, we explore how to build an Industrial Knowledge Fabric that unifies operational and enterprise data using agents, UNS (Unified Namespace), Azure OpenAI, vector databases, FastAPI, and modern retrieval architectures. We will walk through conceptual and implementation architectures—both local and Azure‑native—using Azure AI Search, Qdrant, LangGraph, Azure SQL, React frontends, and sensor‑driven measurement repositories. If you're working in digital transformation, AI‑powered operations, or IIoT modernization, this session will give you a blueprint for turning chaotic data streams into infinite insights.

Azure Foundry Models Industrial Internet of Things Intermediate
02

The Guardian in the Machine: Architecting Cloud-Native Governance with Azure AI

Angshuman Bhattacharya

As AI transitions from experimental "chatbots" to mission-critical enterprise infrastructure, the industry faces a massive gap: we have "Software Risk" experts, but who are the "AI Risk Architects"? This session bridges that void. We will explore how to move beyond model accuracy to prioritize Responsibility, Explainability, and Observability. Leveraging Azure AI Content Safety, Azure Machine Learning’s Responsible AI Dashboard, and Azure Monitor, we will build a technical "Citadel of Trust." Finally, we align these cloud-native tools with the IndiaAI Mission’s goals for safe, sovereign, and ethical AI development for the next billion users.

Azure Machine Learning AIGovernance Intermediate
03

Unlocking Azure Observability with Grafana: Mastering the Azure Monitor Data Source

Ayan Bhadury

Learn how to leverage Grafana’s Azure Monitor data source to unlock deep observability across your Azure environment. In this session, we’ll explore how to query and visualise metrics, logs, traces, and resource data from services like Azure Monitor, Application Insights, and Azure Resource Graph all within a unified Grafana experience.We’ll cover key capabilities such as building dynamic dashboards, using Kusto Query Language (KQL) for log analysis, setting up alerts, and combining multiple Azure data sources into a single pane of glass. By the end, you’ll understand how to turn Azure telemetry into actionable insights for performance monitoring, troubleshooting, and operational excellence

AKS Observability Intermediate
04

The Era of Agentic AI: From Copilots to Autonomous Enterprise Systems

Sayantan Sengupta

Agentic AI is transforming enterprise architectures—from copilots that assist users to intelligent agents that plan, act, and collaborate across systems. This session explores how architects can design production‑ready agentic AI solutions on Azure, focusing on scalable patterns, platform choices, and responsible AI guardrails. Learn how to embed security, governance, observability, and human‑in‑the‑loop control to move agentic AI from experimentation to trusted, enterprise‑grade deployment.

07

Breaking the Kernel Bottleneck: High-Performance Networking with Azure CNI & eBPF

Suman Chakraborty

Standard Linux networking was never designed for the churn and density of modern container workloads. When production clusters hit the limits of IPTables, latency spikes and CPU consumption can bring services to their knees. This talk explores the next generation of AKS networking: Azure CNI Overlay with Cilium. We will walk through the architectural differences between VNET-integrated and Overlay networking, specifically focusing on how eBPF bypasses traditional bottlenecks. By the end of this session, attendees will have a clear understanding of performance benchmarking metrics at scale, the technical trade-offs of overlay networking, and a roadmap for migrating production workloads to a more performant, eBPF-driven future.
